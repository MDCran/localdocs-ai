# Product design

The interface uses a Nord inspired base: dark slate navigation, soft neutral surfaces, and muted green accents for local and source states. The layout favors a compact sidebar and legible tables. Light and dark themes share the same status colors, focus states, and spacing.

Collections set the search boundary. Document rows keep processing state close to each file. Chat separates collection scope and document filters from the question. Source cards link answers back to page aware passages and original files. Retrieval diagnostics expose method, score type, candidate count, model, and timing without presenting relevance as confidence.

Empty, error, upload, failed job, and no evidence states are built into the flows. Responsive navigation, visible keyboard focus, operable dialogs, status labels, semantic headings, reduced motion support, and readable source excerpts support accessibility. The product illustration is drawn in CSS.
