# Roadmap

- Add optional OCR for image only documents.
- Compare chunking strategies with a larger, versioned question set.
- Add an optional local reranker if retrieval tests show a consistent gain.
- Add resource estimates for long documents and slower CPUs.
- Improve PDF text selection and source highlighting.
- Add optional encrypted backups after defining key ownership and recovery.
- Consider authentication only alongside a supported multiuser and remote hosting threat model.
